Android Link PMR — BETA
Версия 4.0-BETA

===============================================================
НАЗНАЧЕНИЕ
===============================================================

Приложение Android Link PMR предназначено для связи через сеть
PMR (Private Mobile Radio) с радиостанцией, подключённой к
телефону через аудиоразъём 3,5 мм.

BETA-версия предназначена для тестирования. Параметры по умолчанию
установлены так, чтобы упростить проверку на разных телефонах.

===============================================================
КАК РАБОТАЕТ
===============================================================

1. Звук с микрофона телефона сжимается кодеком G711
   (8 бит, 16 кГц) и отправляется на сервер PMR по UDP.

2. Звук от сервера принимается, декодируется и воспроизводится
   в правом канале стерео-выхода телефона.

3. При приёме звука от сервера в левом канале генерируется
   тональный сигнал PTT (частота 100..3000 Гц). Этот сигнал
   используется внешней схемой для управления передатчиком
   радиостанции.

4. VOX — автоматическое определение голоса. Если уровень
   микрофона превышает порог My_Vox, включается передача.

НАСТРОЙКИ
===============================================================

БЛОК VOX
--------

СОСТОЯНИЕ:
  ГОТОВ     — нет приёма, нет передачи.
  ПЕРЕДАЧА  — идёт отправка звука с микрофона.
  ПРИЕМ     — идёт приём звука от сервера.

PTT: ВКЛ/ВЫКЛ — состояние PTT (по приёму).

VOX=N   — текущий уровень микрофона.
MAX=N   — пик уровня микрофона за последние 3 секунды.
RX=N    — текущий уровень принимаемого сигнала.

My_Vox — порог срабатывания VOX. Если VOX больше My_Vox — передача
включается.

Кнопка МАРКЕР — фиксирует текущее значение My_Vox. При фиксации
кнопка краснеет, маркер на полосе блокируется от случайного
перемещения.

vox_pause — время удержания передачи после спада сигнала
(в тиках по 20 мс). 50 тиков = 1 секунда.

vox_mic — усиление микрофона (0..100 %).

PoslePrd — задержка после выключения передатчика, в течение
которой VOX не срабатывает (в тиках по 20 мс).

БЛОК PTT (ТОН НА ЛЕВОМ КАНАЛЕ)
------------------------------

ptt_tone_level (%) — амплитуда тона PTT (0..100 %).
  0 = тон выключен (PTT не работает).

ptt_tone_hz — частота тона PTT (100..3000 Гц).
  По умолчанию 1000 Гц.

БЛОК ВНЕШНЯЯ ЗВУКОВАЯ КАРТА (USB)
---------------------------------

Показывает статус подключения внешней USB-звуковой карты
(для отладки).

РЕГИСТРАЦИОННЫЕ ДАННЫЕ
----------------------

Priznak_pmr — признак PMR-канала. Идёт в каждый передаваемый
  пакет. Должен совпадать у всех абонентов канала.
  Дефолт BETA: 11111.

MyMailIndex — почтовый индекс абонента в системе PMR.
  Дефолт BETA: 11111.

MyPChannel — номер канала PMR.
  Дефолт BETA: 4.

ip_server — IP-адрес сервера PMR.
  Дефолт BETA: 192.168.0.1.

port_prm — порт приёма UDP (локальный).
  Дефолт: 5354.

port_prd — порт передачи на сервер.
  Дефолт: 16000.

onUsilMic — включение усиления микрофона.
  0 = выключено, 1 = включено.

MicUsildouble — коэффициент усиления микрофона.
  Например, 2.0 = усиление в 2 раза.

onUsilDin — включение усиления приёмного тракта.
  0 = выключено, 1 = включено.

DinUsildouble — коэффициент усиления приёма.
  Например, 0.4 = ослабление в 2.5 раза.

Call — позывной.

QTH — город.

log_email — email для отправки логов приложения.

БЛОК СМЕНА ПАРОЛЯ
-----------------

Позволяет изменить пароль приложения.
Дефолт BETA: 12345.
