Android Link PMR — описание программы
Версия 4.0.1
═══════════════════════════════════════════════════════

НАЗНАЧЕНИЕ
───────────────────────────────────────────────────────
Приложение для радиолюбителей, работающих в сети PMR.
Позволяет принимать и передавать голос через IP-сеть,
связывая телефон с радиостанцией.

ПРИНЦИП РАБОТЫ
───────────────────────────────────────────────────────
Микрофон телефона → сжатие G711 → UDP → сервер PMR →
другие абоненты. Приём — обратный поток.
Управление PTT — через тональный сигнал 1000 Гц
(или другую частоту) в левом канале аудиовыхода.

СТЕРЕО-ВЫХОД
───────────────────────────────────────────────────────
Левый канал (L)  — тональный сигнал PTT.
Правый канал (R) — звук от сервера (приём).

РЕГИСТРАЦИОННЫЕ ДАННЫЕ
───────────────────────────────────────────────────────
Priznak_pmr   — признак PMR-канала. Идёт в каждый
                передаваемый пакет. По умолчанию 11111.
MyMailIndex   — индекс абонента в почтовой системе PMR.
                По умолчанию 11111.
MyPChannel    — номер канала PMR. По умолчанию 4.
ip_server     — IP-адрес сервера PMR.
                По умолчанию 192.168.0.1.
port_prm      — порт приёма UDP (локальный). По умолчанию 5354.
port_prd      — порт передачи на сервер. По умолчанию 16000.
onUsilMic     — флаг усиления микрофона:
                0 = выключено, 1 = включено. По умолчанию 1.
MicUsildouble — коэффициент усиления микрофона.
                По умолчанию 2.0.
onUsilDin     — флаг усиления приёмного тракта:
                0 = выключено, 1 = включено. По умолчанию 1.
DinUsildouble — коэффициент усиления приёма.
                По умолчанию 0.4.
Call          — позывной радиолюбителя (например, RW6HHL).
QTH           — город / местоположение.
Email логов   — адрес для отправки логов приложения.
                По умолчанию qrz@mail.ru.

VOX — АВТОМАТИЧЕСКАЯ ПЕРЕДАЧА
───────────────────────────────────────────────────────
My_Vox        — порог срабатывания VOX (0..1000).
vox_pause     — время удержания передачи после спада
                сигнала (в тиках по 20 мс). 50 = 1 сек.
vox_mic       — усиление микрофона (0..100 %).
PoslePrd      — блокировка VOX после выключения передатчика
                (в тиках по 20 мс).

Кнопка «МАРКЕР» — блокирует маркер My_Vox, чтобы
предотвратить случайное смещение.

PTT — УПРАВЛЕНИЕ ПЕРЕДАТЧИКОМ
───────────────────────────────────────────────────────
ptt_tone_level — уровень тона на левом канале (0..100 %).
                 0 = тон выключен, PTT не работает.
ptt_tone_hz    — частота тона (100..3000 Гц).
                 По умолчанию 1000 Гц.

При появлении звука от сервера (приём) — на левый канал
подаётся синусоида с заданными частотой и уровнем.
Внешний транзисторный ключ детектирует тон и коммутирует
PTT радиостанции.

ГРОМКОСТЬ ПРИЁМА
───────────────────────────────────────────────────────
rx_gain       — усиление правого канала (0..100 %).
                50 = 1.0x (штатный уровень).
                100 = 2.0x (в два раза громче).
                0 = звук выключен.

Используется, когда штатный регулятор громкости телефона
установлен на 100 %, но звук всё равно тихий.

ГЛАВНЫЙ ЭКРАН

УСТАНОВКА
───────────────────────────────────────────────────────
1. Установите APK на телефон.
2. При первом запуске введите пароль.
   По умолчанию: 12345.
3. Войдите в «НАСТРОЙКИ» и укажите:
   - Priznak_pmr, MyMailIndex, MyPChannel, ip_server;
   - позывной и QTH;
   - email для логов.
4. Подключите внешнюю схему PTT к левому каналу.
5. Пользуйтесь.

ОГРАНИЧЕНИЯ
───────────────────────────────────────────────────────
- Работает только на встроенном микрофоне и динамике.
- Внешняя USB-звуковая карта не поддерживается.
- ПTT — через внешний транзисторный ключ.
- Минимальная версия Android: 7.0 (API 24).
