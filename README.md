# Android Link PMR — описание работы

**Версия: V4.0.4**
**Платформа:** Android (minSdk 24, targetSdk 34)
**Имя APK:** `app-v4_0_4.apk`
**Пакет:** `com.pmr.admin`

---

## 1. Назначение

Программа предназначена для подключения телефона к радиостанции через
**гнездо наушников** (разъём 3.5 мм). Голосовая связь организуется по IP-сети
с сервером PMR: звук передаётся и принимается по UDP, рация работает как
оконечное устройство эфира.

Коммутация РТТ (передача/приём) радиостанции выполнена аппаратно через
разделение звуковых каналов стереовыхода:

- **Левый канал** — служебный тон. В момент приёма звука от сервера на левый
  канал воспроизводится звуковой сигнал с устанавливаемой частотой (`ptt_tone_hz`)
  и громкостью (`ptt_tone_level`). Левый канал подключается к частотному детектору,
  собранному на микросхеме **lm567**. Детектор управляет транзисторным ключом,
  который коммутирует РТТ радиостанции.
- **Правый канал** — звуковой. По правому каналу передаётся полезный звук
  (принятый голос) в радиостанцию.

Таким образом, наличие тона на левом канале переводит рацию в режим передачи
(РТТ включён), а голос идёт по правому каналу.

## 2. Экраны программы

### 2.1 Splash-экран (приветствие)

Показывается при запуске. Показывает название «Android Link PMR», версию
**«V4.0.4»**, а также позывной (Call) и QTH. Далее программа переходит прямо
к экрану ввода пароля (экран проверки системы в V4.0.4 отсутствует).

### 2.2 Экран ввода пароля (`PasswordActivity`)

Полe для ввода пароля и кнопка **«ВОЙТИ»**. Пароль по умолчанию: `12345`
(меняется в настройках). При верном пароле открывается главный экран.

### 2.3 Главный экран (`MainActivity`)

Содержит **четыре кнопки**:

- **НАСТРОЙКИ** (зелёная) — переход в экран настроек;
- **ПРОВЕРИТЬ ОБНОВЛЕНИЕ** (жёлтая) — проверка новой версии APK (см. раздел 5);
- **КОММУТАЦИЯ** (оранжевая) — открывает схему коммутации (изображение);
- **ОПИСАНИЕ** (синяя) — открывает текст описания программы с прокруткой и
  кнопкой **«ЗАКРЫТЬ»**.

При первом запуске запрашиваются разрешения: запись с микрофона, отправка
уведомлений (Android 13+). Затем запускается фоновый сервис `PmrService`.

### 2.4 Экран настроек (`SettingsActivity`)

Заголовок **«НАСТРОЙКИ V4.0.4»**. Блоки и поля:

1. **Изменение пароля**
   - Текущий пароль, новый пароль, подтверждение нового пароля;
   - опция «Требовать пароль при запуске» (флажок).

2. **Блок PTT**
   - `ptt_tone_hz` — частота тона PTT (левого канала);
   - `ptt_tone_level` — громкость тона PTT (левого канала).

3. **Громкость приёма (R-канал)**
   - `rx_gain` — громкость принятого звука, выводимого на правый канал.

4. **Регистрационные данные**
   - Priznak_pmr (по умолчанию `11111`);
   - MyMailIndex (по умолчанию `11111`);
   - MyPChannel (по умолчанию `4`);
   - IP сервера (по умолчанию `192.168.0.1`);
   - Email для логов (по умолчанию `qrz@mail.ru`).

5. **VOX — голосовое включение передачи**
   - My_Vox (порог срабатывания, по умолчанию `1000`);
   - onUsilMic (флаг усиления микрофона, по умолчанию `1`);
   - onUsilDin (флаг усиления приёма, по умолчанию `1`).

6. **Индикация состояния** (обновляется в реальном времени):
   - **СОСТОЯНИЕ:** ГОТОВ / ПЕРЕДАЧА / ПРИЕМ;
   - уровни `VOX=...` и `RX=...`;
   - статус подключённого аудиоустройства.

Кнопка **«СОХРАНИТЬ»** сохраняет настройки в `SharedPreferences` и перезагружает
UDP-сокет (если он уже запущен).

### 2.5 Экран логов

Показывает журнал работы программы. Поле для e-mail и кнопки:

- **ОЧИСТИТЬ** — очистить лог;
- **ПОДЕЛИТЬСЯ** — отправить/поделиться логом;
- **EMAIL** — отправить лог на указанный email.

## 3. Фоновый сервис (`PmrService`)

Запускается при старте как **foreground service** (не убивается системой).
Выполняет:

- работу UDP-сокета `PmrSocket` — обмен голосом и служебными данными с сервером PMR;
- аудиодвижок `AudioEngine` — приём и воспроизведение звука с сервера
  (тон PTT на левый канал, голос на правый);
- движок `VoxEngine` — захват с микрофона, определение голоса, включение передачи.

В строке состояния показывается постоянное уведомление о работе программы.
Нажатие на уведомление открывает главный экран.

---

## 4. Голосовой тракт (кратко)

- **Приём (RX):** аудиоданные приходят по UDP от сервера, декодируются
  (кодек G.711 µLaw в `G711Ua`), выводятся на USB-аудиоустройство. В момент приёма
  на **левый канал** подаётся тон PTT с частотой `ptt_tone_hz` и громкостью
  `ptt_tone_level` — детектор **lm567** включает РТТ радиостанции; на **правый канал**
  выводится принятый голос (громкость регулируется `rx_gain`).
- **Передача (TX):** микрофон захватывается `VoxEngine`, уровень голоса сравнивается
  с порогом `My_Vox`. При превышении порога включается передача, звук кодируется
  и отправляется на сервер по UDP.

## 5. Проверка обновлений

По нажатию **«ПРОВЕРИТЬ ОБНОВЛЕНИЕ»** программа обращается к репозиторию
`rw6hhl/Android-Link-PMR` и проверяет наличие новой версии. Если обновлений
нет — показывается соответствующее сообщение; если есть — предлагается скачать
и установить APK.

> Примечание: сборка может вестись в режиме **debug** (подпись дебаг-ключом),
> поэтому перед установкой новой версии старую версию приложения, как правило,
> нужно удалить вручную.
